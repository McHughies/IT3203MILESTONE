Research references

The following resources inform the terminology and general recommendations in this milestone. Future updates will add more detailed research and in-text attribution.

  1. OWASP Top 10 ↗

    An overview of major web application security risk categories.

    https://owasp.org/www-project-top-ten/

  2. OWASP Cheat Sheet Series ↗

    Actionable developer guidance on secure implementation practices.

    https://cheatsheetseries.owasp.org/

  3. CISA Secure Our World ↗

    Practical advice on phishing, passwords, MFA, and software updates.

    https://www.cisa.gov/secure-our-world

  4. MDN Web Docs: Web security ↗

    Reference materials on browser and web security topics.

    https://developer.mozilla.org/en-US/docs/Web/Security

  5. W3C Markup Validation Service ↗

    Check HTML documents for markup errors.

    https://validator.w3.org/

  6. KSU IT 3203 course site ↗

    Course homepage and introductory web development learning resources.

    https://ksuweb.github.io/IT3203/
