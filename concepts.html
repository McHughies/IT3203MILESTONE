LEARNING / GLOSSARY

Seven Key Concepts

A quick reference for the language used throughout this project.

01

Authentication

The process of confirming a user or system is who it claims to be.

02

Authorization

The rules determining which resources or actions an authenticated user may access.

03

Encryption

Transforming information using cryptographic methods so it is unreadable without the appropriate key.

04

Vulnerability

A weakness in design, implementation, or configuration that could be exploited.

05

Phishing

A deceptive message or site intended to trick someone into sharing information or taking a harmful action.

06

Multifactor authentication (MFA)

Signing in with two or more independent verification factors, such as a password and an authenticator app.

07

Input validation

Checking supplied information against expected rules before accepting or processing it.

Put the terms together

Authentication confirms an identity, authorization checks permissions, and input validation helps ensure the application processes expected data. These concepts work together rather than replacing one another.
